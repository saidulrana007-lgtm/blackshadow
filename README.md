# Saidul Islam Rana — One Page Cybersecurity Portfolio

GitHub Pages-ready static portfolio.

## Files
- `index.html` — page structure
- `styles.css` — responsive visual system
- `script.js` — dynamic rendering + interactions
- `content.js` — editable capabilities and experience data

## GitHub Pages
Upload all files to the root of a GitHub repository. Keep `index.html` in the repository root. Then enable:

**Settings → Pages → Deploy from a branch → main → / (root)**

No build tool is required.


### Optional profile photo
Place a file named `profile.jpg` in the repository root. The top-left profile box will automatically use it; no HTML editing is required. If the file is absent, a clean `SIR` fallback remains visible.
